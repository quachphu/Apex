# Asme Liquid Glass Hero

A single-page Vite + React 18 + TypeScript + Tailwind CSS 3 hero section with a full-screen cinematic background video, liquid glass UI, and Lucide React icons.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## Build

```bash
npm run build
npm run preview
```

## Main files

- `src/App.tsx` - React hero section and custom requestAnimationFrame video fade loop
- `src/index.css` - Tailwind imports, Google Font import, and `.liquid-glass` styling
- `tailwind.config.js` - default Tailwind config with content paths
